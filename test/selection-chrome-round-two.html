Pointee selection chrome · round two

Four families, fourteen variations

Round one put fourteen structures on the table. Four survived: the Header card, the Primary card, the Strip, and the Overlay pill. This round varies inside each — where every control sits, read literally: the outputs near the identity, Edit beside what it edits, Select Parent on the breadcrumb it climbs — and puts a tooltip on every icon-only button. Same four stages at real scale in the shipped tokens, plus one strip per family showing the four tooltips as they read on hover.

Still fixed

  • The four actions, with their names, all reachable.
  • Every icon-only button names itself in a tooltip on hover.
  • Keyboard hints visible somewhere: Option to measure, Escape to step back.
  • All five readout lines at rest.

What each family varies

  • Header — which controls share the identity row, and where the others go.
  • Primary — where the filled Copy Code sits, and how the three ghosts group.
  • Strip — the card is never wider than its action row; with and without the hints in it.
  • Overlay — which edge of the selection the pill straddles.

How to answer

  • A letter. 02B is an answer.
  • Or a hybrid across families: 02B's rows with 13A's pill.
